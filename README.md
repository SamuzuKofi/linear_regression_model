# Linear Regression Model — Orange Economy Ghana

## Mission
Ghana's creative sector (music, visual art, design, film) has real economic potential, but artists struggle to earn a sustainable living from their craft. This project builds a regression model that predicts a creative freelancer's earnings from measurable factors (job category, experience, skills, ratings, region), so artists can see which factors most affect income and make practical, data-backed decisions to scale up.
